# Лабораторная работа №1
## Разведочный анализ данных. Исследование и визуализация данных


### Описание задания
Цель работы: изучить методы визуализации и выполнить разведочный анализ набора данных.

Задачи:
1. Выбрать датасет.
2. Рассчитать основные характеристики.
3. Провести визуальное исследование данных.
4. Проанализировать корреляции признаков.
5. Подготовить отчетные материалы.

Выбранный датасет: Backblaze hard drive test data (2016 Q1-Q2).

- Источник: https://www.kaggle.com/datasets/backblaze/hard-drive-test-data/data
- Локальный файл: D:/6 сем/тмо/dataset/harddrive.csv

### Текст программы
Основной код расположен в ноутбуке `lab1_exploratory_analysis.ipynb`.

Ключевые этапы:
1. Импорт библиотек и загрузка данных.
2. Анализ структуры, типов и пропусков.
3. Расширенная описательная статистика.
4. Визуализация распределений и boxplot по целевой переменной.
5. Корреляционный анализ и тепловая карта.
6. PCA (2 компоненты).
7. Простая модель RandomForest и важности признаков.

### Экранные формы и примеры выполнения
Выполнение зафиксировано в outputs ячеек ноутбука и сохраненных изображениях в папке `figures/`.

Примеры артефактов:
- `figures/corr_heatmap.png`
- `figures/pca.png`
- `figures/feature_importances.png`
- `lab1_descriptive_stats_extended.csv`
- `lab1_correlation_matrix.csv`

### Краткие результаты
- Размер датасета: 3,179,295 строк и 95 столбцов.
- Для устойчивого анализа оставлено 52 числовых признака (с долей пропусков не более 60%).
- По PCA доли объясненной дисперсии для 2 компонент: 0.1296 и 0.1074.
- Построены и сохранены графики распределений, boxplot, корреляционная карта и важности признаков.

### Как запустить
1. Установить зависимости:
	 pip install -r requirements.txt
2. Открыть и выполнить ноутбук:
	 jupyter notebook lab1_exploratory_analysis.ipynb
