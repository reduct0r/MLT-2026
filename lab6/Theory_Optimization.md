# Теория: Условный экстремум. Метод множителей Лагранжа

## Постановка задачи

Найти экстремум функции $f(x)$, $x \in \mathbb{R}^n$, при ограничениях:

$$g_j(x) = 0, \quad j = 1,\ldots,m \quad \text{(равенства)}$$
$$g_j(x) \leq 0, \quad j = m+1,\ldots,p \quad \text{(неравенства)}$$

---

## Функция Лагранжа

**Классическая** (для ограничений-равенств):

$$L(x, \lambda) = f(x) + \sum_{j=1}^{p} \lambda_j g_j(x)$$

**Обобщённая** (с нормировочным множителем $\lambda_0$):

$$L(x, \lambda_0, \lambda) = \lambda_0 f(x) + \sum_{j=1}^{p} \lambda_j g_j(x)$$

---

## Активные и пассивные ограничения

Ограничение-неравенство $g_j(x) \leq 0$ называется:
- **активным** в точке $x^*$, если $g_j(x^*) = 0$
- **пассивным**, если $g_j(x^*) < 0$

---

## Условия ККТ (Каруша–Куна–Таккера)

Необходимые условия экстремума первого порядка для регулярной точки $x^*$:

**А) Стационарность:**
$$\frac{\partial L(x^*, \lambda^*)}{\partial x_i} = 0, \quad i = 1,\ldots,n$$

**Б) Допустимость:**
$$g_j(x^*) = 0,\ j=1,\ldots,m; \qquad g_j(x^*) \leq 0,\ j=m+1,\ldots,p$$

**В) Знак множителей** (для минимума):
$$\lambda_j^* \geq 0, \quad j = m+1,\ldots,p$$

Для максимума: $\lambda_j^* \leq 0$.

**Г) Дополняющая нежёсткость:**
$$\lambda_j^* \cdot g_j(x^*) = 0, \quad j = m+1,\ldots,p$$

> **Следствие:** если ограничение пассивно ($g_j < 0$), то $\lambda_j = 0$. Если $\lambda_j \ne 0$, то ограничение активно.

---

## Алгоритм решения

1. Составить $L(x, \lambda)$.
2. Записать условия ККТ (А–Г).
3. Перебрать все комбинации активности ограничений-неравенств ($2^{p-m}$ случаев).
4. В каждом случае решить систему уравнений, проверить знаки $\lambda_j$ и допустимость $x^*$.
5. Для найденных кандидатов проверить **достаточные условия** 2-го порядка.
6. Вычислить $f(x^*)$.

---

## Достаточные условия 2-го порядка

Пусть $(x^*, \lambda^*)$ удовлетворяет условиям ККТ. Пусть $l$ — число ограничений-равенств и активных ограничений-неравенств.

**Способ 1 — второй дифференциал:**

Вычислить $d^2 L(x^*, \lambda^*)$ для ненулевых $dx \in \mathbb{R}^n$, удовлетворяющих:
$$dg_j(x^*) = \sum_{i=1}^{n} \frac{\partial g_j}{\partial x_i} dx_i = 0, \quad j = 1,\ldots,l$$

- Если $d^2 L > 0$ — условный локальный **минимум**
- Если $d^2 L < 0$ — условный локальный **максимум**

**Способ 2 — окаймлённый определитель Гессе:**

Для одного активного ограничения ($l=1$, $n=2$):

$$\bar{H} = \begin{pmatrix} 0 & \nabla g_1^\top \\ \nabla g_1 & H_L \end{pmatrix}$$

- $\det(\bar{H}) > 0$ → минимум
- $\det(\bar{H}) < 0$ → максимум

Для общего случая ($l$ ограничений, $n$ переменных) проверяются угловые миноры $\bar{H}$ порядка $2l+1, 2l+2, \ldots, l+n$.

---

## Пример: Вариант 1.4

$$f = 3x_1^2 + 4x_1 x_2 + 5x_2^2 \to \min$$
$$g_1: 4 - x_1 - x_2 \leq 0, \quad g_2: -x_1 \leq 0, \quad g_3: -x_2 \leq 0$$

**Функция Лагранжа:**
$$L = 3x_1^2 + 4x_1x_2 + 5x_2^2 + \lambda_1(4-x_1-x_2) + \lambda_2(-x_1) + \lambda_3(-x_2)$$

**Условия стационарности:**
$$6x_1 + 4x_2 - \lambda_1 - \lambda_2 = 0$$
$$4x_1 + 10x_2 - \lambda_1 - \lambda_3 = 0$$

**Единственная KKT-точка** (активно только $g_1$):

$$x_1 = 3,\quad x_2 = 1,\quad \lambda_1 = 22,\quad \lambda_2 = \lambda_3 = 0$$

**Проверка 2-го порядка:**

Подпространство: $dg_1 = -dx_1 - dx_2 = 0 \Rightarrow dx_2 = -dx_1$

$$d^2 L = 8\,dx_1^2 > 0 \quad \Rightarrow \quad \text{условный минимум}$$

$$\det(\bar{H}) = 8 > 0 \quad \checkmark$$

**Ответ:** $x^* = (3,\, 1)$, $f^* = 44$ — условный минимум.

---

## Частные случаи

| Ситуация | Что делать |
|---|---|
| $\lambda_0^e = 0$ | Нерегулярная точка; целевая функция в условиях не используется |
| $l = n$ и все $\lambda_j > 0$ | Достаточное условие 1-го порядка выполнено (минимум) |
| $d^2 L = 0$ | Необходимо дополнительное исследование |
| Ограничения линейно зависимы в $x^*$ | Условие регулярности не выполнено, $\lambda_0$ может быть 0 |
